# industrial-automation-portfolio

PLC simulation, SCADA supervision and C#/.NET projects for industrial automation.

## About

Portfolio built step by step alongside my Industrial Automation certificate at Polytechnique Montreal.
All projects are simulated on a computer - no physical hardware.

## Projects

1. **C# fundamentals for industrial use** - variables, conditions, loops, methods and basic OOP, practised with industrial examples.
2. **Project 1 - Simulated PLC machine** - a simulated machine (sensors, actuators, sequences, alarms) programmed in IEC 61131-3 logic with CODESYS.
3. **Project 2 - SCADA supervision** - the simulated PLC connected to Ignition SCADA, alarm and data logging in SQL, and a small C#/.NET dashboard.
